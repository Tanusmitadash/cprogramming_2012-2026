Ubuntu/Linux:

 Step 1: Create and open the `.vimrc` file

Open the terminal and run:

```bash
vi ~/.vimrc
```

If the file doesn't exist, `vi` will create it.

Step 2: Enter Insert Mode

Once Vim opens, press:

```text
i
```

You should now be in Insert Mode You can start typing or paste your `.vimrc` configuration.

For example:

```vim
set number
set tabstop=4
set shiftwidth=4
set expandtab
set autoindent
syntax on
```

 Step 3: Save and Exit

After entering the contents, press:

```text
Esc
```

Then type:

```text
:wq
```

And press:

```text
Enter
```

`.vimrc` file is now saved.
